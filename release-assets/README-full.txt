MGS4 Cheat Trainer -- FULL build
================================

This is the fully self-contained build. It bundles the entire .NET 8
runtime inside the exe, so it works on any Windows 10/11 (x64) PC with
zero setup -- nothing to install first. That's also why it's a much
larger download than the LIGHT build.

Usage
-----
1. Start Metal Gear Solid 4 (Master Collection) and load into a level.
2. Run MGS4CheatTrainer.exe (as Administrator if it fails to attach).
3. Use the tabs to toggle cheats, unlock outfits/items, or edit stats.

Note: the first launch may take a few extra seconds while it
self-extracts its native dependencies to a temp cache. Later launches
are fast.

This is an unofficial fan project, not affiliated with Konami.
Single-player/offline use only. See the project's GitHub page for the
full README, source code, and disclaimer.
